# 价值投资助手 v1.0.0

这是价值投资助手的首个公开版本。它将交易、持仓、研究材料和复盘记录放进一个本地优先的桌面工作区，帮助用户持续检验投资判断。

## 主要功能

- 交易记录、持仓成本、收益和资产分布看板。
- 盘前分析、公司研究档案和附件管理。
- 投资心得、读书笔记和历史复盘。
- 自选行情、主要市场和汇率参考信息。
- 用户自行配置 DeepSeek API Key 后进行结构化辅助分析。
- 本地 JSON 导入、导出、备份与恢复。

## Windows 使用方式

1. 下载并解压 Windows x64 压缩包。
2. 保留解压后的完整文件夹。
3. 双击 `价值投资助手.exe` 运行。

本程序暂未进行商业代码签名，Windows 可能显示“未知发布者”或 SmartScreen 提示。

## 隐私与安全

- 发布包不包含 API Key、OAuth 密钥、登录令牌或用户投资数据。
- DeepSeek API Key 由用户自行配置并保存在本机。
- 公开版本不内置百度网盘 OAuth 凭据；一般用户可使用本地文件夹备份。
- 本工具不构成投资建议，行情仅供参考。
